
# Datheon Java Programming Internship

## Task 2: Bank Account & ATM Simulation Engine

### Project Description
This project is a Java-based Bank Account and ATM Simulation System developed using Object-Oriented Programming concepts.

### Features
- Savings Account
- Checking Account
- PIN Verification
- Deposit
- Withdrawal
- Balance Enquiry
- Interest Calculation
- Overdraft Limit
- Transaction History
- Custom Exception Handling

### Technologies Used
- Java
- Object-Oriented Programming
- Inheritance
- Abstraction
- Polymorphism
- ArrayList
- Exception Handling

### How to Run
1. Open the project folder.
2. Open the terminal.
3. Compile the program:

   javac -d . Task-2/ATM.java

4. Run the program:

   java ATM
